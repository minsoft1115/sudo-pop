## 2. 세부 영역별 전수 점검 결과

### 2-1. 메모리 및 프로세스 하드닝 (`src/harden.rs`, `src/secret.rs`)

* **[검증] 코어덤프 및 프로세스 추적 차단 ([`harden.rs:15-33`](../src/harden.rs#L15-L33))**:
  * 프로세스 기동 즉시 `PR_SET_DUMPABLE = 0` 및 `RLIMIT_CORE = 0` 적용. 크래시 시 비밀번호가 디스크 코어덤프로 유출되지 않음.
* **[검증] 메모리 락 및 힙 재할당 방지 ([`secret.rs:22-53`](../src/secret.rs#L22-L53))**:
  * `Secret` 생성 시 `CAPACITY = 2048` 바이트를 선할당하고 즉시 `libc::mlock` 수행하여 스왑/최대절전 이미지 기록 차단.
  * GUI 입력 위젯에서 `MAX_CHARS = 256`으로 입력을 제한하여(최대 1024바이트) 버퍼 재할당으로 인한 미보호 메모리 생성 가능성을 원천 배제.
* **[검증] 안전한 메모리 소거 및 전송 ([`secret.rs:69-73, 124-134`](../src/secret.rs#L69-L73))**:
  * `zeroize`를 통한 명시적 메모리 소거(`wipe()`) 및 `Drop` 구현.
  * `PasswordChannel::send`에서 `println!`이나 포맷 매크로 없이 원시 `write_all`로 바이트 스트림을 전송하여 지워지지 않는 메모리 사본 생성을 방지.
* **[검증] 표준 출력 격리 ([`secret.rs:98-122`](../src/secret.rs#L98-L122))**:
  * askpass 모드에서 `take()` 호출 시 실제 stdout fd를 `dup`으로 보관한 후 fd 1을 `/dev/null`로 치환.

### 2-2. D-Bus 서비스 및 에이전트 수명주기 (`src/main.rs`, `src/agent.rs`)

* **[검증] 발신자 위조 차단 ([`agent.rs:142-150`](../src/agent.rs#L142-L150))**:
  * `BeginAuthentication` 호출 시 `header.sender()`를 `org.freedesktop.PolicyKit1`의 현재 고유 버스 이름과 대조. 일치하지 않으면 창을 띄우기 전에 `AccessDenied` 에러로 즉시 거절.
* **[검증] polkitd 재시작 경쟁상태(TOCTOU) 방지 ([`main.rs:204-220`](../src/main.rs#L204-L220))**:
  * 소유자 고유 이름을 읽기 전에 `receive_name_owner_changed` 구독을 먼저 등록하여 기동 중 polkitd 재시작 신호 유실 방지.
* **[검증] 등록 충돌 및 systemd 재시작 폭주 방지 ([`main.rs:247-260`](../src/main.rs#L247-L260))**:
  * 등록 실패 원인이 `already exists for the given subject`인 경우 정상 종료(`Ok(())`)하여 `Restart=on-failure` 무한 재시작 루프 방지. 일시적 D-Bus 오류는 exit 1로 종료하여 systemd 복구 지원.
* **[검증] PID 재사용(PID recycling) 공격 면역 ([`agent.rs:274-285`](../src/agent.rs#L274-L285))**:
  * 자식 프로세스 제어를 위해 raw PID 대신 `pidfd_open`으로 얻은 `pidfd`를 `running` 맵에 보관하고, 취소 시 `pidfd_send_signal` 사용.
* **[검증] 대기 큐 선행 취소 처리 ([`agent.rs:165-172`](../src/agent.rs#L165-L172))**:
  * 이전 요청 처리 중 큐에 대기하던 요청이 polkitd로부터 취소된 경우, 턴 락(`_turn`) 획득 후 `take_cancelled`로 확인하여 창 없이 즉시 정상 종료.

### 2-3. PAM 헬퍼 통신 및 비밀번호 재시도 제어 (`src/helper.rs`, `src/prompt.rs`, `src/attempts.rs`)

* **[검증] 헬퍼 연결 이중화 및 폴백 ([`helper.rs:101-140`](../src/helper.rs#L101-L140))**:
  * `/run/polkit/agent-helper.socket`을 먼저 시도하고, 커널 `SO_PEERPIDFD` 미지원 등으로 프롬프트 없이 닫힐 경우 setuid 바이너리 fork로 안전하게 폴백.
* **[검증] setuid 바이너리 무결성 검증 ([`helper.rs:58-62`](../src/helper.rs#L58-L62))**:
  * 릴리스 빌드에서 헬퍼 실행 전 `uid == 0 && mode & 0o4000`을 검사하여 변조된 바이너리 실행 방지.
* **[검증] 재발행 무한 루프 방지 ([`prompt.rs:23-25`, `agent.rs:199-206`](../src/prompt.rs#L23-L25))**:
  * 사용자 취소(`EXIT_CANCELLED=2`) 및 프롬프트 전 실패(`RefusedWithoutPrompt`)를 D-Bus 성공(`Ok(())`)으로 반환하여 polkitd의 무한 재발행 방지.
* **[검증] faillock 연동 및 실시간 예산 갱신 ([`prompt.rs:73-98`, `attempts.rs:146-165`](../src/prompt.rs#L73-L98))**:
  * 기동 시 및 매 오답 발생 시 `attempts::budget()`을 조회하여 잔여 횟수를 UI로 실시간 전송(`ToUi::Attempts`).
  * 오답으로 인해 `deny`에 도달하여 계정이 잠겼을 경우(`is_locked()`), 추가 입력을 요구하지 않고 즉시 취소 종료.

### 2-4. sudo 라우팅 및 인수 판별 (`src/wrapper.rs`, `src/sudo_args.rs`, `src/paths.rs`)

* **[검증] run0 라우팅 및 환경변수 보존 ([`wrapper.rs:57-59`, `sudo_args.rs:39-82`](../src/wrapper.rs#L57-L59))**:
  * 순수 명령(`sudo pacman -Syu`)만 `run0`으로 보내고, sudo 옵션(`-E`, `-u` 등)이나 환경변수 할당(`sudo VAR=1 make`)은 `sudo -A`로 유지.
  * `-A`, `-n`, `-S` 등 명시적 플래그가 있는 경우 `-A`를 덧붙이지 않고 원래 의도대로 sudo 실행.
* **[검증] 런타임 디렉터리 권한 검증 ([`paths.rs:41-63`](../src/paths.rs#L41-L63))**:
  * `$XDG_RUNTIME_DIR/sudo-pop` 경로에 대해 심볼릭 링크 여부, 소유자 UID, `0700` 권한을 엄격하게 확인하여 비인가 접근 방지.

### 2-5. GUI 창 렌더링 및 폰트 폴백 (`src/gui.rs`, `src/font.rs`, `src/invocation.rs`, `src/theme.rs`)

* **[검증] 창 보안 및 Hyprland 규칙 ([`assets/sudo-pop.lua`](../assets/sudo-pop.lua))**:
  * app-id `sudo-askpass`에 대해 `float`, `center`, `dim_around`, `stay_focused`, `pin`, `no_screen_share` 강제 적용.
* **[검증] 동적 CJK 폰트 폴백 ([`font.rs:87-129`](../src/font.rs#L87-L129))**:
  * 비 ASCII 문자가 cmdline/message에 포함된 경우에만 `fc-match :charset=...`을 호출하여 CJK 글리프를 체인 뒤쪽에 동적으로 확장 (`◻` 두부 현상 방지).
* **[검증] 실제 실행 명령 표시 ([`invocation.rs:71-95`](../src/invocation.rs#L71-L95))**:
  * `polkit.subject-pid`의 소유자 UID가 현재 사용자와 일치하는지 확인 후 `/proc/<pid>/cmdline`을 읽어 실제 명령 표시 (`run0`의 난수 유닛명 은폐).
* **[검증] 호출자 타임아웃 카운트다운 ([`gui.rs:309-312`](../src/gui.rs#L309-L312))**:
  * D-Bus 25초 타임아웃을 상단에 1초 단위로 표시하며, 5초 이하 시 경고색, 0초 도달 시 잔류 거짓 방지를 위해 자동 숨김.

* **[검증] 타 에이전트 충돌 사전 감지 ([`init.rs:316-382`](../src/init.rs#L316-L382))**:

## 3. 세부 관찰 사항 및 참고 노트

1. **타임존 포맷 (`src/lib.rs:34-46`)**:
   * `stamp()` 함수가 KST 기준(`+9`)으로 오프셋이 적용되어 있습니다. 디버그 로그 출력용 포맷이므로 동작상 문제는 없습니다.
2. **`attempts::budget()` 프로세스 호출 주기 (`src/attempts.rs:225-238`)**:
   * `faillock --user` 셸아웃은 메인 UI 스레드가 아닌 백그라운드 워커 스레드에서 오답 시점에만 1회 호출되므로 UI 프레임 지연 없이 안전하게 동작합니다.

## 4. 결론

sudo-pop 코드베이스는 사양 문서와 100% 일치하며, 보안 요구사항, 프로세스 격리, 메모리 안전성, 프로토콜 예외 처리가 모두 견고하게 구현되어 있음을 확인하였습니다. 별도의 추가 코드 수정이 필요하지 않은 양호한 상태입니다.
