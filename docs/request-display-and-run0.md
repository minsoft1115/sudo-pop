# 요청 표시와 run0 전용 실행

2026-09-28 구현. 인증 메시지·지문 피드백·PAM·polkit 정책은 변경하지 않는다.

## 요청 표시

기본 창에는 명령 요약과 권한 작업 설명을 보여 준다. 명령이 길이 제한이나 실제 표시 너비로
생략되면 명령줄 오른쪽에 돋보기를 표시한다. 명령줄 또는 돋보기를 클릭하면 스크롤 영역에서
전체 수집 명령행과 요청 설명을 확인한다. polkit action ID는 상세 화면 맨 아래에 작은 보조색으로 표시한다. 짧은 명령도 명령줄을 클릭하여
상세 정보를 확인할 수 있다. 펼친 동안은 상단 오른쪽 접기 아이콘으로 전환하며 다시 클릭하면 닫힌다.

아이콘은 고정 크기의 벡터 도형이며 호버/키보드 포커스에는 색만 바뀐다. 창 크기는
상세 보기 상태나 인증 단계가 바뀔 때만 요청한다. 컴포지터가 보고하는 크기의 소수점/반올림
차이 때문에 반복해서 창 크기를 요청하지 않는다.

- 인자는 각각 구분하여 표시한다. 빈 인자, 공백, 따옴표, 역슬래시를 구분한다.
- 제어문자와 방향 제어문자는 이스케이프하고, 잘못된 UTF-8 바이트는 `\xNN`으로 표시한다.
- 표시 문자열은 복사해서 실행할 셸 문법을 보장하지 않는다. 실행 인자를 수정하지 않는다.
- 명령 수집은 16 KiB·256개 인자로 제한한다. 초과하면 `[command data truncated]`를 표시한다.
  일반 요약의 120자 생략과 이 수집 제한은 서로 다르다. 메타데이터도 8 KiB를 넘으면 명시한다.
- `/proc`를 읽을 수 없으면 명령을 확인할 수 없다고 표시하고, 얻은 polkit 작업 정보는 유지한다.
- 명령행은 요청자가 변경할 수 있는 참고 정보다. 실제 실행 작업, 스크립트 내용, 실행 파일
  무결성을 증명하지 않는다. UID 확인은 PID 재사용이나 동일 UID 공격에 대한 보안 경계가 아니다.
- 상세 보기는 인증을 일시 중단하지 않는다. 지문 인증이나 요청 제한 시간은 계속 진행된다.
  창 펼침은 추가 승인 단계가 아니며, 내용 검토 후에만 인증하도록 강제하지 않는다.

## 실행 정책

기본값은 `SUDO_POP_MODE=run0`이다. PATH 래퍼는 설정을 강제하지 않고 그대로 전달한다.
이 버전을 설치하면 기존 래퍼도 새 바이너리의 기본 정책을 따르므로 **호환성 변경**이 된다.

| 호출 | 기본 동작 |
|---|---|
| `sudo COMMAND ARGS...` | 시스템 run0 실행 |
| `sudo -- COMMAND ARGS...` | 구분자 처리 후 시스템 run0 실행 |
| `sudo -v`, `-k`, `-l`, `-E`, `-u`, `-A`, `-S`, `-n` 등 | 지원하지 않는 sudo 옵션으로 거절, 종료 코드 2 |
| `sudo NAME=value COMMAND` | 지원하지 않는 환경변수 할당으로 거절, 종료 코드 2 |
| 인자 없음 | 자체 사용법을 stderr에 출력, 종료 코드 2 |
| `sudo-pop --help` | 자체 도움말, 종료 코드 0 |
| `SUDO_POP_RUN0=0 sudo COMMAND` | 설정 충돌로 거절, 종료 코드 2 |
| run0 후보 없음 | 오류, 종료 코드 2; PATH 검색·sudo fallback 없음 |
| run0 exec 실패 | ENOENT는 127, 그 외 126; sudo fallback 없음 |
| run0 실행 후 취소·거절·명령 실패 | run0가 반환하는 종료 결과 그대로 전달 |

실행 파일은 `/usr/bin/run0`, `/bin/run0`에서만 선택한다. 실행 시 항상 `--`로
옵션과 명령을 구분하고, 명령 인자의 원래 바이트를 전달한다. 디스플레이가 없어도 sudo로
전환하지 않는다. 인증 UI의 선택과 허용 여부는 run0·polkit에 맡긴다.

`SUDO_POP_MODE`의 오타·빈 값은 거절한다. 전용 모드에서 기존 `SUDO_POP_RUN0`는
미설정 또는 `1`만 허용한다. `0`으로 조용히 정책을 바꾸지 않는다.

## 명시적인 호환 선택

- 특정 sudo 기능만 필요하면 `/usr/bin/sudo -v` 등 실제 sudo를 직접 호출한다.
- 기존 혼합 라우팅 전체가 필요한 호출에는 `SUDO_POP_MODE=compat`를 명시한다.
  이 모드에서는 일반 명령이 run0로 가고, sudo 옵션·환경변수 할당·run0 시작 실패는
  종전 sudo 경로를 사용한다. 기존 `SUDO_POP_RUN0=0`도 이 모드에서만 유효하다.
- 기존 sudo askpass 기능은 유지한다. run0 전용 래퍼는 이를 자동으로 호출하지 않는다.
- 이 선택은 호출자의 편의 정책이다. 악성 프로세스의 `/usr/bin/sudo` 직접 실행을 차단하거나,
  시스템 sudo의 setuid를 제거하는 보안 경계가 아니다.

## Omarchy 업데이트 영향

이 머신의 `/usr/share/omarchy/bin/omarchy-update-stay-awake`는 터미널에서
`sudo -v`를 호출한다. 기본 전용 모드는 이를 거절하므로 업데이트 경로가 실패할 수 있다.
`-v`에 가짜 성공을 반환하거나 `OMARCHY_UPDATE_LOGGED`로 자동 예외를 만들지 않는다.

기존 sudo 정책으로 업데이트 전체를 실행해야 할 때의 명시적인 예:

```bash
SUDO_POP_MODE=compat SUDO_POP_RUN0=0 omarchy update
```

이는 의도적으로 실제 sudo를 사용하는 선택이다. run0 전용으로 업데이트 전 과정의
호환성을 보장하는 명령은 아니다. 실제 업데이트는 검증 과정에서 실행하지 않았다.
기존 바이너리는 이 문서의 `SUDO_POP_MODE`를 인식하지 않으므로 새 버전을 설치해야 한다.

## 검증

- 인자 경계·빈 인자·Unicode·잘못된 UTF-8·제어문자·장문·수집 상한·없는 PID 단위 테스트.
- egui 프레임에서 상세 보기 클릭/닫기, 긴 명령 끝부분 보존, 지문→비밀번호 전환 시
  펼침 상태와 높이 검증. 기존 인증 메시지·지문 이펙트 회귀 테스트 유지.
- 가짜 run0 실행으로 NUL 구분 인자 바이트, 종료 코드, 시그널, 파일 부재·실행 권한 오류 검증.
  테스트 주입 경로는 테스트 빌드 내부에만 존재하며 제품 환경변수로 실행 파일을 바꿀 수 없다.
- 실제 CLI에서 옵션 거절·설정 충돌·도움말 검증. 권한 상승이나 실제 인증을 실행하지 않는다.
- 실제 GUI 입력 전달은 `./tests/input-scenario.sh`의 가짜 helper로 별도 확인한다.

- `cargo test --offline --quiet`: 186개 통과(라이브러리 167, main 1, helper 통합 15, CLI 3).
  샌드박스에서는 기존 Unix 소켓 테스트가 차단되어, 소켓 사용이 가능한 환경에서 재실행했다.

- 포맷·diff 공백·셸 구문 검사 통과. 설치된 바이너리나 서비스는 이번 작업에서 변경하지 않았다.

### 명령줄 돋보기 보완

별도 상세 보기 버튼 행을 제거했다. egui 회귀 테스트로 짧은 명령, 120자 요약 생략,
실제 너비 초과, 수집 상한 초과, 펼침 상태의 아이콘 표시를 검사한다. 호버 전후 같은 영역을
유지하고, 컴포지터 크기가 2pt 다르게 보고되어도 추가 크기 변경 명령이 발생하지 않는지 확인한다.

보완 검증: 전체 Cargo 테스트 187개와 실제 GUI 시나리오 3개 통과. 명령줄의 키보드 접근,
상세 보기 열기/닫기, 이후 Unicode·공백 포함 입력 전달을 확인했다.

### 펼친 화면의 가독성 보완

- 펼쳤을 때 기존 요약 명령을 반복하지 않고, 작은 `Request command` 라벨 아래에 전체 명령을 한 번 표시한다.
- 명령은 13pt 고정폭·선명한 기본색, 라벨/보조 안내는 10pt 보조색, 작업 설명은 12pt 일반 글꼴을 사용한다.
- 실제 실행이 검증되지 않았다는 안내는 명령 아래 보조 문구로 한 번 표시한다.
- action ID는 별도 라벨이나 펼침 메뉴 없이 상세 화면 맨 아래에 10pt 고정폭·보조색으로 표시한다.
- 접기 아이콘은 스크롤 밖 상단 오른쪽에 고정한다. 상세 정보와 인증 영역은 여백과 얇은 선으로 구분한다.
- 회귀 테스트에서 명령 중복 제거, 중복 기술 정보 라벨 제거, 명령과 라벨의 글자 크기·색상 차이를 확인한다.
